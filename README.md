# git prep

Lightweight bash + git script to "prep" (prepare) your branch to merge (e.g. mimic creating a "PR")

# Install

1. Copy the [git-prep](./git-prep) script into your _$PATH_
1. _git_ [executes]((https://git-scm.com/docs/git#Documentation/git.txt-PATH)) any command prefixed with "git" as long as it's in your _$PATH_
